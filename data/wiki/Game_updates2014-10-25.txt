==October 25, 2014==

This update includes bug fixes, graphics improvements, and some of the Halloween holiday content.  We expect another update in the next few days with more stuff.

===Halloween Content===

Every 90-120 minutes, a monstrous assault on [[Serbule]] will take place.  There will be a global announcement when it begins.  The creatures' loot includes various kinds of new content.

We are exploring the world of seasonal content for the first time.  There are likely to be some bumps in the road!  But let us know what you think!

===Dungeon Adjustments: [[Serbule Crypt]]===

Added four new loot chests to the Serbule Crypt, to entice players to delve deeper instead of rushing to the second floor thinking that's the whole dungeon.  The first chest is at the end of the corridor that players seem to all miss; the other three are deeper in. (None are on the second floor past Khyrulek.)  Each chest can be opened by all players once per hour, so you can team up to collect the chests.  The loot isn't always amazing, but it has above-average chances for nice level 20 gear.

===Dungeon Adjustments: [[Goblin Dungeon]]===

*Made [[Algapa]]'s spawn rate 5 minutes instead of 1 minute to reduce camping.  Fixed [[Algapa]] encounter so all nearby goblins come running when he's attacked.

* [[Graz]] the bear and [[Xegatis]] the abomination have modestly improved loot drops.

* Psi Mantises (everywhere in the world) have modestly improved loot drops.

* Fixed a bug in the randomly-spawning "Goblin Storage Chests" that kept them from having magical loot - they always had only white-tier gear.

* Fixed quest logic so you can't repeat the fairy-saving quest.

===Favor Bug Fixes===

* [[Blanche]] did not correctly recognize dairy meals when given as gifts.

* [[Lamashu]] liked "stylish shoes," which no longer exist in game; this has been updated to a preference for "Fashionable" shoes.

* [[Yalox]] did not correctly identify drugs when given as gifts.

*[[Silvia]] did not correctly identify items with [[Druid]] skill prerequisites when given as gifts.

===Other Stuff===

* Raven form is now auto-dispelled indoors.  It's intended as a travel form, so indoor use doesn't make sense anyway.  (This restriction will kick in the next time raven form is activated, so if you're already in raven form, please turn it off and on.  No "legacy perma-ravens" please.)

* Cinnamon can now be forged in the werewolf-forest area of [[Kur Mountains]].

* Fixed XP values for crafting Squash Soup.

* Increased the base chance for [[Butchering]] to drop organs. (Note: to further increase chances, seek out an Organ Knife, it's a tool crafting recipe!)

* Tweaked the server code so that if you loose connection and try to reconnect, it cleans up your old connection a second later.  So the next time you try to reconnect, it will work.

* Cow Barding no longer looks like a cow champton.
