===<b>September 1 Update</b>===
No new content this time around... it's time to test out some new tech stuff!

==<b>Unity Update</b>==
This is the first version of the game that uses '''Unity 5.1''' engine instead of 5.0. Please be on the lookout for interesting graphics glitches that just showed up!

'''NOTE:''' If you get black/pink screens when you play, it's because you need to '''turn off OpenGL in the launcher settings!''' This update does not correctly support OpenGL on Windows. Not sure why, something to do with the Unity 5.1 update.

==<b>Movement Fixes</b>==
The character movement system has been largely rewritten. This means that when you're moving around, that's new code.''' SO PLEASE REPORT ISSUES!''' New code is likely to have weird problems.

'''Also, PLEASE REPORT EXPLOITS, EVEN IF YOU REPORTED THEM BEFORE!''' I believe I've fixed all known movement-related exploits (like stun-moving or wall-walking), so I need new info about what I've missed.

==<b>Guilds</b>==
This update includes support for basic guilds. They have ranks, a Message of the Day, a chat tab, and... uh... that's all. But we need your help banging on these basic features! There may be clever ways to abuse the rank privileges, or the message of the day, or who knows what. Please test guilds as best you can! To facilitate testing, guild-creation has currently just a token cost of 250 coins.

Hopefully everything is great with the new guild tech... but if we overlooked something major, we might have to wipe guilds to fix it. So please don't get too attached... you might need to recreate the entire guild down the road. But hopefully not.

==<b>Important Changes</b>==
: - In order to learn a new ability from a trainer or research recipe, you now must already know the lower-level versions of that ability.
: This doesn't apply to abilities you already learned, because that would be very annoying. So if you already learned level 5 of an ability but don't know level 1-4, you can still use level 5. However, you won't be able to learn level 6 until you go back and learn levels 1-4!
: -''' Accounts are now capped to 4 characters each -- you won't be able to make more than that. If you were already over the limit, your characters are still accessible for now, but please delete them down to four! It's not a huge rush, but please do so within a month.'''

==<b>Other Fixes/Changes</b>==
:- removed physics from trombone and xylophone -- bringing out the instruments and putting them away could cause physics crashes
:- Ever-Burn torches now correctly consume wood chips and not fuel oil
:- Fixed dropped appearance of cheeses (Unity 5 conversion bug)
:- Fixed [[Manticore]] sounds so they are localized to the manticores (when manticores return, that is)
:- Fixed missing texture on high-level injector bugs
:- Fixed a bug that let animal handlers send copies of arbitrary monsters to their stables
:- Updated the [[Serbule]] map to reflect the current layout of Serbule. (It's still a placeholder map, just more up to date than the old one.)
:- If you were not in the area when an Elite/Boss monster died, you cannot loot the monster
:- the "ghost chat" feature no longer shows up when text is added to a tab you aren't looking at
:- private messages are now written to your active chat tab (as well as the All and User tabs) so that you don't miss them (a temp fix until we add private-message tabs)
:- when text is added to a chat tab you aren't viewing right now, the tab is marked with a "*" so you can tell there's something new to read there
:- the Group and Guild tabs only show up if you're in a Group or a Guild, respectively
:- your client remembers which custom chat rooms you last entered and will re-enter them when you next log in. (Note: this is client-side. That means all your characters share the same list!)
:- by default you will auto-join the Help and Trade chat rooms. Use /leave Help or /leave Trade to stop being in those chat rooms
:- bug fixes regarding NPC Barters: if the NPC wants two of something, you now actually have to have two of them. If your inventory is overflowing, you no longer lose the bartered item
