==pdate Notes: April 18, 2026==
This update is primarily for one thing: to try to stop Windows Defender Firewall from blocking our game. The game's ability to connect to our server is being blocked for some users (but not all -- including us; we can't reproduce this). We haven't changed any code related to our networking in <i>years</i> so we presume this behavior is due to some new requirement that Microsoft is enforcing. Looking at our code, we make an HTTP web call at startup instead of an HTTPS web call. We've fixed this, and are hoping it appeases Microsoft's inscrutible filter. If it doesn't, remember that you can always whitelist the game yourself. If you want to whitelist by port, the game needs HTTPS access as well as TCP port 9003 access to *.projectgorgon.com.

But we also have a nice allotment of other fixes!
